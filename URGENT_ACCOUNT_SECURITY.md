# URGENT: GitHub Account & Subscription Security Breach Response

## ⚠️ IMMEDIATE ACTION REQUIRED

If your bank card used for GitHub AI subscription has been compromised and you're seeing fraudulent charges, follow these steps **immediately**:

---

## Step 1: Secure Your GitHub Account (DO THIS FIRST)

### 1.1 Change Your GitHub Password NOW
1. Go to https://github.com/settings/security
2. Click "Change password"
3. Use a **strong, unique password** (16+ characters, mix of uppercase, lowercase, numbers, symbols)
4. **Do NOT reuse passwords** from other sites

### 1.2 Enable Two-Factor Authentication (2FA) IMMEDIATELY
1. Go to https://github.com/settings/security
2. Click "Enable two-factor authentication"
3. Use an authenticator app (Google Authenticator, Authy, Microsoft Authenticator)
4. **Save your recovery codes** in a secure location (not on your computer)
5. This prevents anyone from accessing your account even if they have your password

### 1.3 Review Active Sessions
1. Go to https://github.com/settings/security-log
2. Review all active sessions
3. Click "See more" to view all sessions
4. Revoke any sessions you don't recognize

### 1.4 Check Your Security Log
1. Go to https://github.com/settings/security-log
2. Look for suspicious activities:
   - Logins from unknown locations
   - Password changes you didn't make
   - OAuth app authorizations
   - Repository access
   - Billing changes

## Step 2: Secure Your Billing & Subscription

### 2.1 Remove Compromised Payment Method
1. Go to https://github.com/settings/billing/payment_information
2. Remove the compromised credit card
3. **Do NOT add a new card yet** until your account is fully secured

### 2.2 Review Your Subscriptions & Billing History
1. Go to https://github.com/settings/billing
2. Check for unauthorized subscriptions:
   - GitHub Copilot
   - GitHub Pro
   - GitHub Teams
   - Any other services
3. Review billing history at https://github.com/settings/billing/history
4. Document any fraudulent charges (dates, amounts, descriptions)

### 2.3 Cancel Unauthorized Subscriptions
1. If you see subscriptions you didn't authorize, cancel them immediately
2. Go to https://github.com/settings/billing
3. Click on each unauthorized subscription and cancel it

### 2.4 Contact GitHub Support
1. Go to https://support.github.com/contact
2. Select "Account and profile" → "Security"
3. Explain the situation:
   - Your bank card was compromised
   - You see fraudulent charges related to GitHub
   - Request a review of your account for unauthorized access
   - Ask for refunds for any unauthorized charges

## Step 4: Review Other Compromised Access

### 4.1 Check OAuth Applications
1. Go to https://github.com/settings/applications
2. Review "Authorized OAuth Apps"
3. Revoke access to:
   - Apps you don't recognize
   - Apps you no longer use
   - Any suspicious applications

### 4.2 Check GitHub Apps
1. Go to https://github.com/settings/installations
2. Review installed GitHub Apps
3. Remove any you don't recognize

### 4.3 Review Personal Access Tokens
1. Go to https://github.com/settings/tokens
2. Check all personal access tokens
3. Delete any tokens you:
   - Don't recognize
   - Created long ago
   - No longer need

### 4.4 Check SSH Keys
1. Go to https://github.com/settings/keys
2. Review all SSH keys
3. Delete any keys you don't recognize

### 4.5 Check GPG Keys
1. Go to https://github.com/settings/gpg/keys
2. Review all GPG keys
3. Delete any keys you don't recognize

## Step 6: Investigate How This Happened

### Possible Causes:

1. **Phishing Attack**
   - Received fake email appearing to be from GitHub
   - Clicked link and entered credentials on fake site

2. **Malware/Keylogger**
   - Your computer may be infected
   - Malware captures passwords as you type

3. **Browser Extension**
   - Malicious browser extension stealing credentials
   - Review and remove suspicious extensions

4. **Data Breach**
   - Password reused from another breached site
   - Check https://haveibeenpwned.com

5. **Public WiFi**
   - Used unsecured public WiFi
   - Credentials intercepted

6. **Saved Payment Information**
   - GitHub stored your card details
   - Account was compromised, card was used

### Immediate Security Scan:

```bash
# Run these on your computer:

# Check for suspicious processes (Windows)
tasklist | findstr /i "suspicious"

# Check for suspicious processes (Mac/Linux)
ps aux | grep -i suspicious

# Clear browser cache and cookies
# (Do this in your browser settings)

# Update your antivirus and run full scan
```

## Step 7: Prevent Future Incidents

### 7.1 Use Strong Security Practices
- ✅ Use unique password for GitHub (never reuse)
- ✅ Use password manager (1Password, Bitwarden, LastPass)
- ✅ Keep 2FA enabled on all accounts
- ✅ Use hardware security key for 2FA (YubiKey) - most secure option

### 7.2 For GitHub Payments
- Consider using virtual card numbers (Privacy.com, bank virtual cards)
- Use PayPal instead of direct card if possible
- Set up transaction alerts on your card
- Regularly review GitHub billing

### 7.3 Monitor Your Account
- Review GitHub security log weekly
- Check billing history monthly
- Enable GitHub security alerts
- Set up email notifications for account changes

### 7.4 Computer Security
- Install reputable antivirus software
- Keep OS and all software updated
- Don't install software from untrusted sources
- Be cautious with browser extensions
- Use VPN on public WiFi

### 7.5 Watch for Phishing
- Verify email sender addresses carefully
- GitHub emails come from @github.com (check carefully)
- Never click links in unexpected emails
- Go directly to github.com (type it yourself)
- Look for HTTPS and valid certificate
