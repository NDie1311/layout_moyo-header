# Quick Action Guide - Bank Card Compromised on GitHub Subscription

## 🚨 DO THESE 5 THINGS RIGHT NOW (In Order)

### 1. Change GitHub Password (2 minutes)
- Go to: https://github.com/settings/security
- Click "Change password"
- Use a strong, unique password (16+ characters)

### 2. Enable 2FA on GitHub (5 minutes)
- Go to: https://github.com/settings/security
- Click "Enable two-factor authentication"
- Use authenticator app (Google Authenticator, Authy)
- **Save recovery codes somewhere safe!**

### 3. Remove Payment Method (1 minute)
- Go to: https://github.com/settings/billing/payment_information
- Remove the compromised credit card
- Don't add a new one until account is secured

### 4. Call Your Bank (10 minutes)
- Call the fraud number on back of your card
- Say: "I need to report fraudulent charges and cancel my card"
- Request:
  - Cancel current card immediately
  - Issue new card with new number
  - Dispute the fraudulent charges
  - Block any pending GitHub charges

### 5. Contact GitHub Support (5 minutes)
- Go to: https://support.github.com/contact
- Select: Account and profile → Security
- Report the fraud and request account audit

## 🔍 After Securing: Investigate

Check these places for suspicious activity:

1. **GitHub Security Log**: https://github.com/settings/security-log
2. **OAuth Apps**: https://github.com/settings/applications
3. **Personal Access Tokens**: https://github.com/settings/tokens
4. **SSH Keys**: https://github.com/settings/keys
5. **Billing History**: https://github.com/settings/billing/history

Delete/revoke anything you don't recognize!

---

## 🛡️ Prevent This Again

After everything is secured:

1. **Use virtual card numbers** for subscriptions (Privacy.com, Apple Card)
2. **Never reuse passwords** - use a password manager
3. **Always use 2FA** - preferably with hardware key
4. **Monitor accounts** - check billing monthly
5. **Run antivirus** - scan your computer for malware
6. **Check for phishing** - never click email links for sensitive sites

---

## ⚠️ Common Scams to Avoid

**Fake GitHub Emails:**
- Real GitHub emails come from `@github.com`
- Look for `noreply@github.com` or `support@github.com`
- Check the actual email address (not just display name)
- Hover over links before clicking
- When in doubt, go directly to github.com (type it yourself)

**Phone Scams:**
- GitHub will never call you asking for passwords
- Your bank may call but will never ask for full card number
- When in doubt, hang up and call the official number yourself
